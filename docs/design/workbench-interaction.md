# URLPut 界面交互设计

打开 [可点击原型](workbench-prototype.html) 即可演示。页面使用内置示例数据，刷新重置。演示运行在当前页面，模拟任务每隔约 4.5 秒推进，也可用「推进一步」控制节奏。原型不上传文件、访问目标站点、发送模型请求或执行投稿。

## 推荐演示路线

1. 总览点「开始演示」，选择 CSV、Excel、TXT 或粘贴。用示例清单预览原始行、列映射、重复项和无效网址。
2. 点「继续确认」，选「仅分析」或「分析后执行（模拟）」，启动批次。
3. 在「任务与待办」查看已处理行数、进度、状态筛选和事件。暂停、继续或手动推进。论坛任务进入人工待办后，目录站和博客仍会继续。
4. 打开论坛待办，演示暂不处理，再打开并标记已确认。其余任务处理完毕但论坛待办仍在时，批次显示「等待人工处理」。待办解决并运行完毕后，进度达到 100%。
5. 打开批次报告，检查原始行、阶段结论和下一步。切回总览或打开 Chrome 侧边栏，看到同一批次进度。设置页可切换本地与自建模型并模拟连接。

## 页面职责

| 界面 | 用户看到的信息与动作 |
| --- | --- |
| Chrome 侧边栏 | 查看批次进度和人工待办数量，打开工作台或直达任务。 |
| 总览 | 当前站点、批次进度、原始行与人工待办摘要，进入导入和报告。 |
| 导入清单 | 选来源与工作表，配置表头和列映射，预览重复及错误，确认执行方式。 |
| 任务与待办 | 行号、域名、状态、当前动作和进度事件，支持暂停、继续及进入具体人工待办。 |
| 批次报告 | 原始行序号、域名、分类、网址、结果类别、结论、原因与下一步。支持查看阶段结果和演示导出。 |
| 推广站点 | 当前站点的品牌身份、允许推广的页面与发布账号信息。 |
| 设置 | 本地和自建模型两份配置，分析与文案独立开关，连接测试与保存。 |

## 状态与进度口径

- 分母是原始行数。已分析或核验完毕、重复跳过、输入无效分别计入已处理行。人工待办继续留在分母，并单独列出。
- 批次暂停时停止自动推进，保留行状态和事件。人工任务只暂停对应行。所有可运行任务完成而待办未解决时显示「等待人工处理」，仍可查看阶段报告。
- 执行任务展示具体动作和原因。分别记录平台接收、待审核、公开可见和外链有效等状态。仅分析模式不把可用入口计为投稿成功。
- 原型演示一个批次及固定样本。导入来源控件、模拟导出、品牌档案与模型设置用于走查界面，正式实现再接入相应数据和服务。
