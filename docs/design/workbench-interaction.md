# URLPut Chrome 侧边栏交互设计

[打开可点击原型](workbench-prototype.html)。示例以约 392 像素宽的 Chrome 侧边栏展示。首页包含「新建批次」和「任务进度」，低频 AI 配置收入右上角「设置」。原型使用模拟任务与浏览器本地存储。

## 新建批次

1. **推广站点清单**保存要推广的网站。可粘贴多行批量导入，在清单里搜索、勾选、全选匹配或清空。清单保存和批次选择是两个操作。示例提供 100 个站点。
2. **外链清单**是投稿目标，一份清单可由选中的各个站点共用。提供 CSV、Excel、TXT、粘贴入口。原型为前三种提供内置样本，粘贴可进行本地解析。正式导入在折叠区域内逐级展开工作表、列映射与错误预览，确认后收起。
3. **启动预览**显示选中站点数、每站候选上限和组合总数。选择 100 个站点，载入 1,000 条候选，每站上限设为 1,000，预览显示 **100,000 个组合**。确认后创建批次，保留当时选中的两个清单。组合数是检查范围，实际投稿尝试依历史、平台归并及执行结果而定。

推广站点清单、外链清单、执行确认合并在一个面板。常用内容保持展开，导入细节按需查看。大型清单在侧边栏显示数量和预览，正式实现使用搜索与分页访问完整清单。

## 任务进度与记录

- 整体进度、暂停与继续、人工待办在同一个视图。站点选择器可切换到单站进度，待办显示具体的「推广站点 → 目标外链」。
- 示例运行数秒后出现一条模拟人工待办，其他组合继续推进。可暂停、继续或点「推进一步」，处理完待办后总进度达到 100%。仅分析的处理结果与真实投稿核验分开记录。
- 「记录与导出」在任务进度内折叠显示。原型展示少量样本，并能下载真实的演示 CSV。一个站点或全部站点均可导出当前范围的演示样本。后续修改推广站点、外链或每站上限，可以切回已有批次核查原批次快照。

## 记录与导出约定

| 记录 | 保存内容 |
| --- | --- |
| 推广站点 | 稳定站点 ID、名称、主页 URL、所属工作空间。批次保存选中的站点引用及快照，站点后续改名仍可追溯。 |
| 外链候选与原始行 | 原始外链 URL、规范化 URL、来源文件、工作表、原始行号和关联的候选。合并重复候选时保留所有原始行。 |
| 站点与外链任务 | 批次 ID、推广站点 ID、候选 ID、任务状态、结果、原因、外链证据及更新时间。按两端身份回查。 |
| 报告与导出 | 在既有报告前七列后追加「推广站点」「推广站点网址」。既有 URL 列保留原始外链 URL。正式 CSV 与 Excel 统一此结构，按批次或批次内站点筛选。演示 CSV 使用精简列，显式包含两端网址。 |

正式实现应按批次保存站点和候选集合，分段调度任务，并分页读取进度和结果。100 个站点 × 1,000 条外链的 100,000 条组合无需在侧栏一次性创建或渲染。最终发表防重仍使用「推广站点 + 平台」的原子约束，每个推广站点的状态独立记录。
