# URLPut Chrome 侧边栏交互设计

[打开可点击原型](workbench-prototype.html)。示例以约 392 像素宽的 Chrome 侧边栏展示。顶部包含「新建批次」「任务」「清单」「内容模板」「AI 模型」「认证方式」。原型使用模拟任务与浏览器本地存储。

## UI 视觉

- 以 392 px 宽为主要预览尺寸，320 px 侧栏内仍保留完整导航。顶栏固定，正文使用单列，清单预览在卡片内滚动。
- 浅灰紫底色、白色卡片、靛紫主操作。步骤编号跟随执行方式，已有的统计集中在启动确认卡片内。普通操作使用浅色描边或文字按钮。
- 任务用进度条、百分比和已处理数量一起表达进度。黄色提示等待处理，绿色表示完成，灰色表示暂停或停止。每个状态同时保留文字。
- 批量检查使用醒目的主按钮。需单独确认的卡片使用黄色背景和说明。表单和弹窗沿用相同的输入控件和键盘焦点样式。

## 新建批次

| 分析后执行 | 仅分析 | 步骤及交互 |
| --- | --- | --- |
| 1 | 1 | **推广站点**。按域名搜索，或只看有待提交外链的站点。每站显示总外链、已提交、待提交。可全选匹配结果或清空选择。 |
| 2 | 2 | **外链清单**。选一份共享清单，展开后查看活跃外链的域名、网站类型和完整 URL。搜索及类型筛选仅作用于浏览，批次使用所选清单的活跃条目。 |
| 3 | 3 | **执行方式**。「仅分析」检查入口可用性和投稿要求。「分析后执行」把分析与后续执行合在同一批次，按授权、内容和额度继续。 |
| 4 | 4 | **投稿内容**。按分类预选各组默认模板。所有模板组都能多选，通用文案也可同时选多份。仅分析时保留选择，切换执行方式即可使用。 |
| 5 | 隐藏 | **认证与二次确认**。使用工作空间的账号策略，确认允许的登录、注册、邮件检查和发表方式。 |
| 6 | 隐藏 | **提交频率**。设置每站滚动 24 小时额度、单站例外和每日执行。 |
| 7 | 5 | **批次设置**。最后配置可选批次名称和每站候选上限。 |
| 8 | 6 | **启动前确认**。显示执行方式、已选站点数、候选数及待提交数，再启动任务。 |

启动前确认里的组合数等于已选站点数乘以应用每站上限后的候选数。100 个站点分别选用 1,000 条候选时共有 100,000 个组合。已确认被平台接受的条目计入「已提交」，包括明确待审核。「待提交」是差额，已分析但未提交仍在其中。正式尝试数还取决于平台去重、活跃状态和是否需要人工核验。

### 从批次补充清单

「去清单补充站点」「去清单补充外链」直达清单里对应的录入区。返回时保留批次名称、站点选择、所选清单、模板、额度和周期配置。新增站点可自动勾入，新保存的清单可带回选用。独立进入清单使用同样的检查和维护流程。

新建批次与清单管理的站点列表、外链明细首屏各 5 条，向下滚动接近底部时自动追加 5 条。切换清单或筛选时回到首屏。全选站点覆盖全部匹配项，包括尚未加载的记录。网站类型未知时显示「未识别」。

## 每日额度与周期续跑

- 「分析后执行」可设置每站滚动 24 小时尝试上限。设置一个默认值，并为选中的单个站点覆盖额度。限额按站点跨批次共享，多个有效限制同时适用时取最小值。同一站点未来批次仍检查已经消耗的额度。
- 勾选「每天执行，自动续跑」后，任务在下一周期继续剩余工作。关闭后可手动启动下一轮，手动操作也受滚动额度限制。原型可点击「模拟 24 小时后」检验两轮处理、限额与跨天恢复。页面只模拟时间和提交，不执行真实投稿。
- 下一周期只重试已确认发生在发表动作之前的临时失败。无法确认是否已经点击或接收时进入只读核验。已提交和明确终止的记录保留结果。正式执行在点击前原子检查并占用额度和唯一投稿名额。
- 「中断」保留检查点并挂起调度。「停止」关闭自动执行并保留结果。两者都能手动继续，按保存的额度和检查点恢复。

## 任务、历史与进度

任务页按最近创建顺序显示批次，支持名称或编号搜索、状态筛选和分页。未完成批次打开进度，已完成批次直接打开结果。同一个批次详情用于查看阶段报告和历史结果。

| 状态 | 进入方式与可用操作 |
| --- | --- |
| 执行中 | 启动或继续后进入。可暂停，也可确认中断。 |
| 已暂停 | 临时停止调度，可继续或改为中断。 |
| 已中断 | 挂起批次，保留进度与阶段结果。可从保存的进度继续。 |
| 已停止 | 关闭自动执行，保留已记录结果。手动继续可恢复原计划。 |
| 待下轮 | 当前站点额度不足或有提交前临时失败。等待符合额度的后续周期。 |
| 待核验 | 发表后缺少可信回执时继续只读检查。历史保留原有操作和证据。 |
| 待人工 | 剩余可自动处理部分完成，继续前需处理待办，也可中断。 |
| 已完成 | 所有组合达到终态后自动进入，提供结果和导出。 |

正式实现从持久化检查点恢复。已经确认的结果继续保留，发表状态不明确的任务进入只读核验。任务列表和结果分页读取，侧栏保留当前筛选。

### 批次详情

- 整体进度、暂停与继续、人工待办在同一个视图。站点选择器可切换到单站进度，待办显示具体的「推广站点 → 目标外链」。
- 示例运行数秒后出现一条模拟人工待办，其他组合继续推进。可暂停、继续或点「推进一步」，处理完待办后总进度达到 100%。仅分析的处理结果与真实投稿核验分开记录。
- 「记录与导出」在任务进度内折叠显示。原型展示少量样本，并能下载真实的演示 CSV。一个站点或全部站点均可导出当前范围的演示样本。后续修改推广站点、外链或每站上限，可以切回已有批次核查原批次快照。

## 历史清单维护

- 「清单 → 推广站点」支持批量添加、按域名查找、编辑同域名的网址和确认删除。删除后退出新批次选项，已启动批次使用原快照。重新导入同一域名沿用原站点身份和投稿历史。
- 「清单 → 外链清单」按名称管理多份已保存清单。清单名按文件名或序号生成。可查看和编辑内容，支持单份和全部活跃外链导出 CSV。新建批次直接选用同一份清单。
- 清单维护影响后续批次。已启动和已完成批次保留推广站点名称、站点网址和外链内容快照，继续从任务页查看或导出。原型用浏览器本地存储保存任务与清单，便于刷新后复查。

### 检查并导入

填写或上传后点「检查站点」或「检查外链」。结果显示新增、已有、清单内重复和有问题的数量及明细。检查完成即保存新增有效项，已有及重复项跳过。可下载问题行 CSV，包含源行号、原值和原因，方便修正后重新提交。站点按规范化域名识别，外链按规范化 URL 识别。站点 CSV 提供含全部文字资料和图片网址的表头模板，网站网址必填。

外链检查失败、超时、入口关闭或失效时排除该条。活跃外链退出或恢复时以最新检查更新清单，并保留历史任务快照。原型用 `offline.example`、`timeout.example` 和 `closed.example` 展示常见失败，附件支持 TXT 和单列 CSV 的外链示例。正式文件导入和检查还需接入真实访问、表格列映射和 Excel。

### 推广站点投稿资料

点击「查看／编辑」维护站点资料。目录投稿常用资料包括产品名称、行业或分类、资料语言、关键描述、产品介绍、作者或公司（二选一）和产品图片。可补充核心功能、关键词、联系邮箱、Logo 和优先推广页面。产品图片支持在站点编辑中多张上传，也可录入多个图片网址，一行一个或用分号分隔。CSV 可带图片网址，图片文件在编辑页上传。界面允许先保存已有资料，并标出缺项。正式执行按目标表单实际必填项核对，缺少必要资料时进入人工待办。已创建的任务保留当时的资料快照。

## 记录与导出约定

| 记录 | 保存内容 |
| --- | --- |
| 推广站点 | 稳定站点 ID、名称、主页 URL、所属工作空间。批次保存选中的站点引用及快照，站点后续改名仍可追溯。 |
| 外链候选与原始行 | 原始外链 URL、规范化 URL、来源文件、工作表、原始行号和关联的候选。合并重复候选时保留所有原始行。 |
| 站点与外链任务 | 批次 ID、推广站点 ID、候选 ID、任务状态、结果、原因、外链证据及更新时间。按两端身份回查。 |
| 问题行 CSV | 原始行号、原值、未导入原因。 |
| 活跃清单 CSV | 清单名、来源类型、来源行、外链 URL、网站域名、网站类型。按单份或全部清单导出。 |
| 任务报告与导出 | 在既有报告前七列后追加「推广站点」「推广站点网址」。既有 URL 列保留原始外链 URL。正式 CSV 与 Excel 统一此结构，按批次或批次内站点筛选。演示 CSV 使用精简列，显式包含两端网址。 |

正式实现应按批次保存站点和候选集合，分段调度任务，并分页读取进度和结果。100 个站点 × 1,000 条外链的 100,000 条组合无需在侧栏一次性创建或渲染。最终发表防重仍使用「推广站点 + 平台」的原子约束，每个推广站点的状态独立记录。


## 跨任务共享处理状态

任务页的「运行并发去重演示」会启动两个包含相同推广站点和外链的模拟任务。第二个任务先显示「等待共享结果」，第一个任务异步完成后，第二个任务显示「已跳过」及原批次结果。

正式执行以工作空间、稳定推广站点 ID 和规范化外链 URL 组成共享键。看到已有终态时直接关联处理结果，进行中的记录订阅或轮询原任务状态，尚未处理的记录才可原子认领。每完成一个组合就持久化结论并更新关联任务，无需等整批结束。历史跳过不消耗每日额度。仅分析的结论可供同阶段复用，实际提交另有执行状态。


## 投稿内容模板

顶部「内容模板」统一维护标题、正文和每个分类的默认模板。原型支持 `{{站点名称}}`、`{{站点网址}}`、`{{产品名称}}` 和 `{{关键描述}}`，预览时用本条任务所属站点的资料填充。

新建批次选择「分析后执行」后，在「投稿内容」里选择方式。选项在新建批次页可见，仅分析模式不会用它撰写或提交。已保存模板按最新新增优先展示，可搜索、分页和确认删除。删除默认模板时，由同分类的首个剩余模板接替。该分类无剩余模板时取消预选。已创建批次保留所用模板快照。

- **从内容模板选择**：新批次预选每个分类的默认模板，可多选或调整。每条任务先匹配目标入口类型，再从适用的选中模板里随机取一份。没有专用模板时可用已选的通用文案，目标入口的操作流程保持一致。无适用模板则转人工，尚未尝试提交。保存模板版本和草稿。重试复用同一份草稿，修改模板只影响之后创建的批次。
- **AI 根据目标网页拟写**：使用目标网页的主题、字段要求及允许使用的站点资料。
- **AI 分析 + 模板**：从与入口匹配的选中模板起草，再按目标网页主题和要求调整。模型或有效网页内容不可用时，两种 AI 方式均进入人工待办。原型只展示示例页面摘要和模拟草稿。

从任务结果点「另存为内容模板」可编辑草稿再保存。当前站点名称和网址会替换为通用变量，保存后新模板出现在管理列表顶部。

变更某类默认项只影响该类。在新建批次里的勾选同样只作用于本次批次。

批次详情展示内容策略，逐条记录可展开查看实际使用的模板或 AI 草稿。前往「管理内容模板」可直接在模板页编辑并返回原批次。内容模板保存标题和正文，后端外链模板知识库存的是网页表单控件和字段规则。


### 按入口区分模板

| 模板分类 | 填写字段 | 文案与页面操作 |
| --- | --- | --- |
| 目录收录 · 站点简介 | 产品名称、官网、关键描述、分类、产品图片 | 使用产品资料型表述，核对分类和必填信息，填写独立官网字段，校验表单后提交。 |
| 社区推荐 · 资源推荐 | 板块、推荐标题、推荐理由、正文链接 | 结合板块主题说明适合哪些读者，检查板块允许推荐，插入正文链接并预览后发布。 |
| 通用文案 | 标题、正文、站点变量 | 没有匹配的专用模板时从已选通用文案中使用一份，实际填写和发表仍依据目标入口。 |

有不同字段或操作流程时才分场景。同一入口仅措辞变化的版本归入同一类。通用文案可以复用标题和正文，填写方式仍按实际入口识别。原型示例清单的前两条外链分别模拟目录收录和社区推荐。正式执行根据实际 DOM、入口用途和规则判定，单凭网站域名或网址路径不足以选定流程。


## AI 模型

通过顶部「AI 模型」切换本地模型或自建服务，两种类型各自保留配置。填写 API 基础地址、模型名和可选密钥，分别控制 AI 分析和 AI 文案。配置页提供「测试连接」，测试只发送固定消息。批次选择 AI 文案方式后，遇到模型不可用或提取不到有效网页内容时，任务卡说明原因并转人工。

## 第三方登录与待确认

顶部「认证方式」按工作空间管理多条登录邮箱，直接维护邮箱登录默认邮箱、默认密码方案和独立的 Google 默认邮箱。需要填写站点密码时，用户可在浏览器中选用已有的匹配密码，或在目标站登录表单使用自己的其他方案。批次保存选中的账号策略和方案引用。站点资料中的对外联系邮箱单独维护。批次可控制 Google 登录、Chrome 已保存密码、注册新账号、已授权的 Gmail 邮件检查和发表前确认。

| 需要用户处理的情况 | 任务卡动作 |
| --- | --- |
| Google 选账号或授权、账号身份不符 | 打开目标站的官方入口。用户核对指定 Google 邮箱并完成账号选择、授权或二次验证，返回后复核。 |
| 邮箱和密码登录 | 打开目标站。优先用 Chrome 针对同源和同一账号保存的密码，包含 Google 生成并同步的站点密码。没有匹配项时用户可手动选用其他方案或填写。 |
| 已注册但邮箱未验证 | 保留原注册记录。提示前往邮箱验证或在目标站输入验证码，完成后复核同一账号。 |
| 已注册但密码错误 | 保留账号和检查点，暂停该条。给出「打开登录页」和目标站官方找回密码入口。用户可核对已知凭据，也可自行重设。 |
| 重设后重新登录 | 在目标站使用原账号登录并完成所需验证，回到待办点「检查并继续」。核对通过后由用户处理 Chrome 的更新密码提示。 |
| 首次登录及必要验证成功 | 如果 Chrome 提供保存提示，用户可保存或暂不保存。遇到 Chrome 解锁或确认，交由用户处理。 |
| 付费、回链、发表审批 | 展示目标、范围及原因，提供单条确认和跳过。 |

已注册后登录失败时复用原账号，其他任务继续。系统保留失败原因及后续验证结果。用户可手动切换已知方案，系统不会轮试密码或重新注册。按同源和账号核对通过后，从原检查点继续。用户拒绝保存、Chrome 未弹出提示或用户已在浏览器中处理提示时，可直接继续已验证的任务。

顶部「任务」显示待确认数量，任务页的「待确认清单」汇总所有批次。卡片显示推广站点、目标网址、原因、操作指引和快捷入口。完成后可单条点「检查并继续」，或勾选及全选可检查项后一次复核。复核读取当前页面并核对账号和所需状态。找不到完成信号的待办保留原位。付费、回链、发表授权和 Chrome 密码保存需逐条确认。正式执行可在授权后从 Chrome 通知直达待办，并在发现可信完成信号时复查。Gmail 自动查信单独授权，仅唯一匹配的邮件可进入后续核验。

任务页「运行认证流程演示」使用模拟流程。「演示复用 Google 保存的密码」展示 Chrome 有匹配密码、用户手动填写和从官方入口使用 Google 登录三个分支。演示只持久化账号、方案标签、默认设置和模拟的同源匹配结果，表单示例密码刷新后清空。实际密码保存与更新由 Chrome 密码管理器和用户处理。密码找回、重新登录核对及更新保存属于正式交互设计。任务记录只保留目标来源、账号标识、状态、时间和原因。
