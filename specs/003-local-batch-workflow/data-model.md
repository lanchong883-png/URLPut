# 数据约定

| 记录 | 身份、关系与恢复 |
| --- | --- |
| 站点和外链清单 | 当前工作空间内稳定站点 ID、命名清单 ID、规范化候选 URL。来源行保留文件或粘贴来源、行号、原始值及问题原因。活跃状态和评分来源、日期各自记录。 |
| 批次 | 工作空间、启动 ID、批次 ID、快照版本、站点、候选、来源、每站上限、模式和配置版本。启动状态可补齐索引和入队。 |
| 组合与检查点 | 批次、阶段、站点和候选定位组合，分段保存结果和下一位置。工作空间、阶段、站点和规范化 URL 定位可共享结果。正在执行的工作可恢复确认，已落盘终态复用。 |
| 尝试与额度 | 推广站点、已识别平台、来源组合、草稿标识与批准时刻。尝试与额度在同一受锁提交中确认，结果未知保留占位。 |
| 回执与证据 | 平台接收记录、公开 URL、定位依据、预期和实际目标、核验时间、状态及回访失败原因。旧版字段与 CSV 顺序继续读取。 |
