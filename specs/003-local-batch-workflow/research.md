# 调研与决定

| 问题 | 决定与依据 | 复核点 |
| --- | --- | --- |
| 旧数据兼容 | 当前目录已有站点、批次、回执和分段队列文件。沿用 ID 与读取路径，多站快照与本机清单用版本化附加记录。 | 旧 v1 目录、移位重绑、备份恢复与 legacy 迁移复测。 |
| 创建与入队中断 | 使用稳定启动标识和可恢复的提交状态，索引及队列可补写。继续沿用目录及队列的文件锁顺序。 | 并发确认、取得授权后中断、快照提交后进程退出。 |
| 批次大小 | 存站点和有序候选集合，按索引计算逻辑组合，分段落盘与分页读取。 | 100 × 1,000 计数、仅打开需要的分段。 |
| MV3 生命周期 | 先在真实扩展探测 IndexedDB 目录句柄、执行上下文和 Chrome 唤醒。持久检查点负责回收中断工作。后台运行期间的调度须独立于侧栏。 | 浏览器重启、侧栏关闭、目录权限失效、睡眠后的恢复。若后台句柄不支持，复核 Chrome 支持的扩展文档上下文方案。 |
| 全局限速 | 现有 `activeUrlLock`、`queueFilesLock`、请求 timeout 和 Retry-After 规则作为基线。后台及旧入口共享同一槽位，跨唤醒保留必要退避时间。 | 多窗口、限流跨唤醒、运行中切换目录、空闲无轮询。 |
| 模型与防重 | 已有模型连接测试可复用，但实际草稿生成单独验收。阶段内分析复用按站点与 URL，最终发表占位按站点与已识别平台。共享托管域名需证据才能归并。 | 默认模型、缺密钥、失败、同平台不同 URL、共享托管、回执不明。 |
