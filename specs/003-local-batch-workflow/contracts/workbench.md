# 工作台行为约定

- **清单与建批** 五区块顺序沿用原型，八区块只在分析后执行时显示。启动确认使用当前选择重算，授权拒绝或校验失败留在确认区。提交成功后打开同一批任务。
- **任务与恢复** 详情支持全批和单站。用户操作明确显示暂停、中断和停止的不同后续状态，均有对应的人工继续动作。目录失权保留当前草稿及已持久化检查点。
- **核验与导出** 来源任务保留待人工、待审核与未确定记录。已确定的公开核验单独入账，保留最近确定结论及暂时失败原因。导出延续原九列顺序。
- **人工投稿** 界面逐条批准或跳过。保存唯一占位后才打开平台入口。用户在目标站点提交，并可回到原记录登记或核对回执。
