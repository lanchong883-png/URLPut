# 功能规格 · 03–10 本机多站批次

**日期** 2026-11-24
**状态** 已确认，实施中
**依据** [实施计划](../../docs/planning/implementation-plan.md) · [交互说明](../../docs/design/workbench-interaction.md)

## 场景与验收

### P1 · 03–05 清单与多站建批

用户维护推广站点和命名外链清单，从保存的清单选出候选，为多个站点启动同一批分析。独立验收从准备两站、两份清单开始，到启动、关闭侧栏、重开并导出同一批为止。

- **FR-031** 支持站点搜索、查看、编辑、确认删除及同域重导。稳定身份和历史关联可追溯。外链清单支持多份保存、默认命名、搜索维护、导出单份或全部活跃外链。
- **FR-032** 接受 CSV、TXT、表格和网址粘贴。反馈新增、已有、重复与问题行，保留全部原始来源，问题 CSV 含原值、行号、原因。解析通过与入口检查通过分别记录。用户发起只读检查，失效、超时及过期项可追溯且不可选。
- **FR-033** 每批选多站和一份清单。站点由用户选，外链默认全选。搜索筛选只改变可见项，「只选筛选结果」替换全量选择。覆盖类型、价格、历史样本链接属性及 DR。区分 DR 0 和未知，并展示已授权评分的来源与日期。列表首屏 5 条，每次追加 5 条，条件变化回首屏。补录返回保留适用草稿与焦点。
- **FR-034** 仅分析按五区块显示。确认区根据站点、候选和每站上限显示组合及待接收数。已明确接收且待审核的组合计入已接收。零候选或零站点禁用启动，主机授权拒绝后保留确认区和草稿。
- **FR-035** 同一次启动至多生成一个批次。保存站点、候选、来源及配置快照，清单编辑与删除后仍可复查。关闭侧栏后仍能处理，重开浏览直接进入同一批进度、结果和 CSV。

### P2 · 06–08 任务、执行控制与结果

用户在任务页恢复进行中的工作，并能区分分析结果、待确认事项和具有公开证据的外链。

- **FR-061** 按创建时间列出任务，支持名称、编号、状态查询和分页，全批或单站展示候选、已处理、待处理、已接收及有效数。汇总跨批待确认的站点、目标和原因。
- **FR-062** 暂停暂缓调度，中断挂起且保存检查点，停止关闭自动执行。三者均可人工继续。关闭侧栏继续执行，浏览器重启可从检查点恢复。复用同阶段重叠组合结果，失败项记录原因并释放执行槽。
- **FR-063** 同一浏览器配置所有批次、清单检查和回访共用串行请求规则。超时、限流和中断可追溯，空闲时无轮询。
- **FR-064** 可解释的分析终态进入已完成网站分析。有明确公开证据的外链进入台账，区分有效、明确失效和下线。待审核、初次核验不确定及待人工留在源任务。回访暂时失败保留上次确定结论和本次失败原因。
- **FR-065** 按站点和状态筛选导出，保留现有 CSV 前九列及批次、原始 URL、来源行、预期和实际目标、证据与时间。

### P3 · 09–10 八区块配置与人工投稿

用户配置分析后的草稿准备，逐条审阅并在目标站点手动提交，回到 URLPut 登记回执并公开核验。

- **FR-091** 八区块增加投稿内容、认证与二次确认、提交频率。切到仅分析时隐藏三块，切回恢复草稿。分类默认模板可多选，模板和混合策略无模板时禁用启动，纯 AI 隐藏模板区。记录配置、模板版本和实际文案来源，续跑复用已生成草稿。
- **FR-092** 在确认后的授权模型设置中生成草稿。未配置、连接失败、资料不足和需要认证进入待确认，显示原因与官方处理入口。系统默认模型可用性单列查验。
- **FR-093** 逐条展示站点、目标与草稿供批准或跳过。进入目标平台之前保存尝试及唯一占位。用户在平台手动完成登录、验证和发表。最终防重按推广站点和已识别平台，未知平台或结果不明停在待核对。
- **FR-094** 执行站点滚动 24 小时额度，支持跨批共享、单站覆盖、最低有效上限、自动续跑和手动下一轮。尝试占位与额度同次确认。重启沿原策略恢复，未明尝试只核对原记录。
- **FR-095** 分别记录平台接收、公开和有效链接。公开后核验同一记录与目标链接，保留来源行并导出证据。正式实站验证使用获授权站点，由用户提交。

## 关键实体与边界

推广站点、外链清单及来源行独立维护。批次快照固定站点、候选和配置。组合执行记录关联检查点、分析结果或人工待办。发表尝试和回执关联来源批次，公开核验保存独立证据。旧批次、回执和 CSV 继续可读。本机流程业务服务关闭时可用，启用本地业务 API 后独立回归旧工作空间和迁移。凭证留在已授权范围。

## 成功标准

- **SC-03** 两站、两清单样本通过导入、筛选、补录回焦和重导身份检查。两站各选上限三条显示六项；100 × 1,000 显示 100,000，分页展示与分段调度。重复确认及启动中断恢复后均只有一个批次，历史快照不随清单改动。关闭侧栏仍处理。
- **SC-06** 两窗口交叉触发检查、分析与回访，主动请求峰值为 1，间隔不少于 2 秒，超时 15 秒并应用 Retry-After。暂停、中断、停止及继续符合各自语义。重启后已落盘项重复请求为 0，空闲时无轮询。
- **SC-08** 对照至少一条分析终态、待审核、公开有效、失效、下线和暂时回访失败样本，核对页面归属、计数和 CSV 字段，确认前九列兼容。
- **SC-10** 测试时钟覆盖滚动额度与断线，重叠批次中同一站点和已识别平台最多打开一个已占位尝试。获授权测试站点取得一次用户手动提交的可追溯回执。公开后核验并导出，待审核期间保持待公开。
- **SC-ALL** 每阶段在 320 px 和 392 px 核对侧栏、键盘焦点和状态。业务服务关闭时本机业务 API 请求数为 0。另启本地 API 验证旧工作空间访问和重复迁移去重。
