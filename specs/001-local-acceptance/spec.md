# 功能规格 · URLPut 本机版验收

**日期** 2026-11-23

**状态** 范围与计划已确认，验收进行中

**代码基线** `handoff/local-acceptance` 的 `f60336e`

## 用户场景与测试

### P1 · 本机管理批次

推广人员在桌面 Chrome 打开扩展，选择测试目录和推广站点，
导入 CSV、TXT 或粘贴表格，保存后重开浏览器并导出原批次。
业务服务关闭期间，批次归属、来源行和导出结果均可核对。

### P1 · 延续未完成工作

推广人员在批次检查或批量回访期间关闭浏览器，重新打开后手动继续。
已保存条目保持原结果。用户移动目录、撤销授权或从备份恢复后，
可选回有效目录并继续原有工作。

### P2 · 管理手动投稿证据

推广人员逐条批准候选文案，在授权平台手动完成一次投稿，
随后登记接收回执。评论公开后，推广人员核验目标链接并导出证据。
相同推广站点和规范化候选网址的重复投稿被拦截。

### 边界场景

- 目录移动或授权失效时提示重新选择或授权，并可回读原批次。
- 限流、超时和单条失败可追溯，其他符合条件的条目可继续。
- 投稿断线后先核查平台状态。公开页面缺少证据时保持待核实，
  暂时访问失败保留上次核验结论。

## 需求

- **FR-001** 业务服务关闭时，用户可导入、保存、回读及导出三个来源的批次。
- **FR-002** 用户可重新绑定或授权目录，以及将备份恢复到另一个空目录。
- **FR-003** 检查和回访应串行执行，用户可从存档位置手动续跑并查看失败原因。
- **FR-004** 投稿必须逐条批准、由用户在平台提交，并在同一推广站点内跨批次防重。
- **FR-005** 回执须关联来源行。确认有效外链须有公开评论与目标地址的匹配证据。

### 关键实体

- 推广站点与导入批次，包含来源行和结果。
- 本机数据目录及其备份，包含批次和恢复所需记录。
- 执行队列，包含任务顺序、结果和续跑位置。
- 投稿批准、待审核回执和核验记录。

## 成功标准

- **SC-001** 真实 Chrome 中三种导入来源均可保存、重启回读并导出，
  本机工作流的业务服务请求为零。
- **SC-002** 目录移动、权限撤销及备份恢复三项验收均可回读原数据。
- **SC-003** 至少各执行一次批次和回访中断续跑，已保存条目重复执行数为零。
- **SC-004** 在获授权站点完成一次投稿、回执关联和公开链接核验，
  CSV 可追溯来源行，同一候选的重复尝试被拦截。

## 假设与范围

采用已有本机版用途作为规格基线。真实安装和权限行为仍待复测，
真实投稿还需站点授权及公开审核。自动投稿、外部账号集成和生产部署
留在后续规格。验收步骤见[本机版规范与验收](../../docs/requirements/local-acceptance.md)。
