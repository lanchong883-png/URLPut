# 本机数据模型

- **工作空间**保存目录格式版本、工作空间 ID、名称和推广站点。
  目录句柄由浏览器保存，重新绑定时读取目标目录的工作空间。
- **批次**以站点和批次 ID 定位，包含创建时间和原始导入数据。
  每个站点有批次索引。迁移以批次 ID 防重。
- **队列与结果**记录执行顺序、已保存结果和恢复位置。
  批量回访的结果与续跑位置保存在同一核验台账文件。
- **投稿批准**关联站点、候选网址、来源批次、来源行和审核文案。
  进入平台前持久化开始状态。
- **回执**关联来源行，记录实际提交时间和平台接收证据。
  待审核状态随原批次回读。
- **核验台账**按推广站点保存公开地址、链接证据和回访结果。
  可读取旧版链接数组及包含回访队列的格式。

存储入口见 `apps/extension/lib/local-directory.ts`。
