# 功能规格 · 01–02 侧栏入口与目录权限恢复

**功能分支** `002-sidepanel-directory-recovery`
**日期** 2026-11-24
**状态** 已确认，进入实施
**依据** [本机版实施计划](../../docs/planning/implementation-plan.md) · [交互说明](../../docs/design/workbench-interaction.md)

## 用户场景与验收

### P1 · 在侧栏继续原来的建批

1. 已有目录且正在编辑建批草稿时，撤销授权后回到侧栏。六项导航和原区块仍可见，就地提示，依赖目录的操作禁用。
2. 在原区块点击「重新授权原目录」。取消或拒绝后，原区块、已填写内容和已解析预览仍可见，用户可重试。重授成功后刷新原工作空间数据，保留草稿并把焦点还给原控件。原控件不可聚焦时回到该区块标题。
3. 第一次使用时，从当前建批区块进入设置，初始化空目录或绑定已有目录。成功后回到原区块。取消后仍可返回草稿。

### P2 · 管理已有数据

1. 从设置查看目录名称、授权状态及最近写入。选择移动后的旧目录可读回原工作空间。选择无效目录、取消或复制失败时，原选定工作空间保持可恢复。
2. 备份到空目标，从备份复制到另一个空目录，成功后切换到恢复目标。核对旧批次、原始行、回执、结果和未完成队列，后续写入进入当前绑定，源目录和备份保留。
3. 切换到另一个工作空间后重新校验站点和已有清单引用，对不可用项提示重新选择。发现正在执行的任务时暂停换绑或备份操作，给出可稍后重试的反馈。

### P3 · 在窄侧栏操作

1. 通过 Chrome 工具栏打开真正的右侧面板，在 320 px 和 392 px 下逐项检查六项导航、设置和全页备用入口，长 URL 无横向溢出，键盘可完成目录恢复。
2. 对照原型记录两个模式的五或八个编号区块、默认展开态、字段、启动条件、清空外链后的禁用状态及清单往返焦点。正式扩展在本阶段交付现有单站流程的侧栏外壳及状态反馈，完整建批与模式配置依后续阶段交付。

### 边界情况

移动目录后原句柄不可读、浏览器不支持选择器、复制中断、跨窗口换绑以及写入中途失权均需提供可执行的恢复路径。写入结果不明时，重授后先核对现有记录，避免重复保存或重跑已落盘项。

## 功能需求

- **FR-001** 保留六项导航及全页备用入口。沿用固定顶栏、浅灰紫底、白色单列卡片、靛紫主操作及卡片内滚动。加载、空、错误和禁用有可见反馈，进度同时使用文字、数值和颜色。
- **FR-002** 设置集中展示目录状态，提供初始化、绑定、换绑、备份和恢复。无可靠写入记录时显示「暂无记录」。
- **FR-003** 失权时留在原建批区块，允许直接重授。恢复授权后还原当前面板会话的草稿和焦点，取消或拒绝可重试。
- **FR-004** 对切换后的站点和清单按目标工作空间重新校验。恢复移动目录时按原工作空间身份匹配。
- **FR-005** 缺权限或写入未完成时保留未确认内容和可恢复检查点。只在持久化确认后显示保存成功。
- **FR-006** 新目录、旧目录和备份恢复均支持业务服务关闭时工作，原有记录和文件格式兼容。

### 关键实体

目录绑定关联用户选择的位置和工作空间身份。建批草稿包含本次编辑内容、当前区块、引用和焦点。历史数据包含批次、来源行、回执、结果及队列检查点。

## 成功标准

- **SC-001** 两个目标宽度均通过六项导航、键盘顺序、长 URL、状态反馈和焦点核对。保留原型和基线撤权证据。
- **SC-002** 在两个宽度各完成一次撤权、取消或拒绝、再次授权，草稿和预览与撤权前一致，回到原区块。
- **SC-003** 空目录、已有目录、移动、备份恢复各通过一次。对照样本的历史 ID、来源行、回执及检查点逐项一致，新写入仅落当前目标，源与备份保留。
- **SC-004** 模拟保存失权及任务运行中换绑。在原目录恢复后确认同一笔保存至多出现一条，已确认队列结果零重复，未完成项可继续。在业务 API 和数据库均关闭时，上述本机目录流程的业务 API 请求数为 0。随后由开发方启动本地业务 API，用测试数据验证旧版服务工作空间可访问、历史可迁移且重复迁移不产生重复记录，单独保留请求与迁移证据。用户也可独立复验。

## 假设与范围

草稿恢复覆盖侧栏仍打开期间的撤权和设置往返。已确认写入和队列检查点跨浏览器重启恢复。首次提供现有清单引用的校验约定，保存多份清单和多站建批安排在 03–05。后台执行器改造、八区块正式配置及投稿闭环依主实施计划推进。
