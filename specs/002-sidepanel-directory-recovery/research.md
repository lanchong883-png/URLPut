# 调研与决策

## 侧栏与草稿

- **决定** 在保有六项主导航的顶栏新增设置入口，故障提示留在当前建批区块。把草稿、来源区块和返回焦点保存在面板会话。
- **依据** 当前 `ImportWorkbench` 用 `legacy || dir` 决定挂载 Workbench。窗口聚焦发现失权后 `dir` 变为空，组件卸载。草稿与可用句柄需要各自的生命周期。
- **评估过的方案** 将草稿默认持久化跨重启会增加额外副本、清理和隔离要求。本阶段采用当前会话草稿，已保存队列仍支持重启续跑。

## 目录身份与提交

- **决定** 使用现有工作空间 ID 关联候选数据，通过目标句柄验证和持久绑定成功提交切换。移动目录可恢复原工作空间，备份恢复时仍验证其中的引用。
- **依据** `workspaceFor` 解析版本化工作空间文件，`openDirectory` 验证旧目录，`copyDirectory` 先复制业务 JSON，最后发布 `workspace.json`。沿用已有执行锁和文件锁。
- **评估过的方案** 目录名称可能重复且移动后可能改变，适合显示用途。目录句柄用于访问目标，工作空间 ID 用于数据关联，同 ID 的备份仍需校验实际内容。

## 写入结果不明

- **决定** 以持久化成功为确认点。已有队列继续使用磁盘检查点，未确认的手动保存以稳定操作标识核对原目标后重试。
- **依据** 分段结果、保存批次和队列位置可能先后完成。失权后需测试记录已提交但调用方尚未收到结果的路径。应只补足复现路径需要的持久恢复状态。
- **评估过的方案** 无条件重放会产生重复批次或重跑已落盘的结果。为所有操作引入通用后台队列超出本阶段范围。
