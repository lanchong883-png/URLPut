# 侧栏界面行为约定

| 入口或状态 | 可观察行为 |
| --- | --- |
| 工具栏 | 打开右侧面板，顶栏保留六项导航、设置和全页工作台入口。 |
| 首次使用 | 建批保留当前区块，提供「打开设置」。设置允许初始化空目录或绑定已有数据。 |
| 已授权 | 设置显示目录、状态和最近确认写入。当前建批沿用单站选择、导入预览和保存。 |
| 失去授权 | 原区块显示「重新授权原目录」，目录读写动作禁用。已填写内容保留。 |
| 原目录恢复 | 原区块重新可用，原控件可用时聚焦，否则聚焦区块标题。 |
| 挑选取消、拒绝或目录移动 | 恢复入口可重试。旧位置不可读时提供去设置重新绑定的路径。 |
| 切换或恢复 | 先验证目标并保存绑定，成功后用目标重新校验选择，提示失效引用。 |
| 运行冲突、复制失败 | 显示原因及重试动作，保留原绑定与已确认数据。 |
| 保存结果不明 | 显示待确认状态。重新授权后核对目标记录，再恢复保存或续跑。 |

以 [规格](../spec.md) 的 FR-001 至 FR-006 为准。设置返回点记录来源区块与触发控件，键盘顺序随可见页面，异步提示由可访问的状态消息反馈。
