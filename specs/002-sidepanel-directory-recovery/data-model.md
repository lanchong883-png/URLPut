# 数据模型

| 实体 | 字段及关系 | 校验与生命周期 |
| --- | --- | --- |
| 目录绑定 | 现有目录句柄、工作空间 ID、显示名称、权限、最近确认写入 | 启动读取绑定。权限与实际读取分开验证。成功持久绑定后启用新工作空间。无时间记录显示暂无记录。 |
| 建批草稿 | 现有输入、解析预览、选中站点、当前区块、返回焦点及可用清单引用 | 原目录失权后保留。恢复后重读工作空间。跨工作空间保留通用输入，验证或清除引用。文件源失效时提示重新选择。 |
| 未确认写入 | 原工作空间及目标、稳定操作标识、待确认内容或已持久化检查点 | 失败和结果不明时保留。恢复原目标后先核对，再补足或重试。跨工作空间隔离。 |
| 备份与恢复 | 来源句柄、空目标、原工作空间及业务 JSON | 复制成功后提交恢复目标绑定。中断时继续使用原目录，另选空目标重试。 |

授权状态从检查中进入未绑定、可用、需重授或读取失败。管理操作期间单独显示进行中，失败返回原状态或提示继续授权。检查和写入结果均关联当前绑定版本，旧操作返回不得更新新绑定界面。
